# tianyixian.github.io

田一贤的个人学术主页,基于 [academicpages](https://github.com/academicpages/academicpages.github.io) 模板(源自 [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) Jekyll 主题)搭建,版式参考了 [kailv69.github.io](https://kailv69.github.io/)。

## 页面结构

- 首页 `/`:个人简介、News、教育经历、科研经历、项目、荣誉奖项、技能
- 简历页 `/cv/`:详细 CV,并提供 [PDF 版](files/cv.pdf)

## 本地修改方法

- 全站配置(姓名、头像、联系方式、社交链接):编辑 `_config.yml`
- 首页内容:编辑 `_pages/about.md`
- 简历页内容:编辑 `_pages/cv.md`
- 头像:替换 `images/profile.jpg`
- 简历 PDF:替换 `files/cv.pdf`

推送到 `main` 分支后,GitHub Pages 会自动重新构建部署。
